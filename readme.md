## Setup

1. Make sure you have Node.js v22.19.0 or higher installed
2. If you use nvm, run: `nvm use` to switch to the correct Node.js version
3. Install dependencies: `npm install`
4. Start development server: `npm run dev`
5. Build for production: `npm run build`
